# Goals Index Auto-Sync (sync-md) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `sync-md` CLI subcommand that deterministically regenerates `goals/index.md` from SQLite state, and wire it into the existing `goal add` / `task add` / `task update` subcommands so the index stays in sync without manual intervention.

**Architecture:** `scripts/sync_md.py` is a small module exporting a pure function `render_index_md(goals, tasks_by_goal, header_text) -> str`, a file-I/O function `sync_index_md(goals_root: Path) -> SyncResult`, and a small `compute_completion_pct()` helper. `scripts/cli.py` gains a `sync-md` subcommand and a shared `_autosync_index_md()` helper invoked from three existing subcommands after the main operation succeeds. No DB schema changes; no new dependencies.

**Tech Stack:** Python 3 stdlib (`pathlib`, `re`, `json`, `dataclasses`), pytest with subprocess-based CLI tests, the existing `argparse` CLI scaffold.

**Spec:** `docs/superpowers/specs/2026-08-04-sync-md-design.md`

## Global Constraints

These are binding on every task below. The reviewer will check each one.

- **Pure function boundary.** `render_index_md(goals, tasks_by_goal, header_text) -> str` does no I/O — it only formats the markdown string. All filesystem reads / writes happen in `sync_index_md(goals_root)`.
- **No DB access in `sync_md.py`.** The file-I/O function reads goals / tasks from DB via `db.list_goals()` and `db.list_tasks()`; the pure function takes them as arguments. (Plan §3, Spec §3.)
- **All goals rendered.** `db.list_goals(status=None)` — no status filter. Render active → paused → completed, in that fixed order. (Spec §2 row "List scope".)
- **Empty groups omitted.** When a status group has zero goals, no `## <status>` heading is emitted. (Spec §4.2.)
- **Sort within group.** `sorted(goals, key=lambda g: g["slug"])` — Unicode codepoint order; slugs are `[a-z0-9-]`. (Spec §4.4.)
- **Completion percentage.** Integer `0..100`. Counts only `status == "done"` toward completion. Returns `0` for empty task list (not a division error). (Spec §4.3.)
- **Header preservation.** Anything before the first `- [` link line in `goals/index.md` is preserved byte-for-byte. From that line onward, the file is fully regenerated. (Spec §4.5.)
- **Em-dash separator.** `- [<name>](<slug>/goal.md) — 状态：<label> — 完成率 <P>%`. The `—` is U+2014. Status labels: `active → 进行中`, `paused → 已暂停`, `completed → 已完成`. (Spec §4.2.)
- **Atomic write.** `sync_index_md` writes to `goals/index.md.tmp` then `Path.replace()` to `goals/index.md`. Avoids partial-write corruption. (Spec §4.6.)
- **Auto-trigger is non-fatal.** `_autosync_index_md()` in `cli.py` captures all exceptions and writes them to stderr; never raises, never exits. (Spec §5.5.)
- **Auto-trigger fires on actual change only.** `subcommand_task_update` calls `_autosync_index_md()` only when the prior `task["status"]` differs from the new status (i.e., the no-op idempotent path does not trigger sync). (Spec §5.5.)
- **CLI surface.** `python scripts/cli.py sync-md [--json]`. No positional args, no other flags. (Spec §5.1.)
- **Exit codes.** `0` = success (warnings allowed); `1` = input error (reserved); `2` = DB uninitialized OR I/O failure. (Spec §5.4.)
- **JSON output shape.** `{path, synced_count, by_status, changed, unchanged, warnings, header_preserved}`. (Spec §5.3.)
- **Idempotency.** Second consecutive `sync-md` produces byte-identical `goals/index.md` (header preserved, list regenerated from same DB state). (Spec §7 #3.)
- **Orphan policy.** Directory in `goals/<slug>/` with no DB row → stderr warning, do NOT add to index, exit 0. DB goal row whose `goals/<slug>/goal.md` is missing → render the link anyway, stderr warning, exit 0. (Spec §2 row "Orphan policy".)
- **No new dependencies.** Pure stdlib. (Spec §2.)
- **Test isolation.** Subprocess-based CLI tests with isolated `TODO_DB_PATH`. CWD redirected to `tmp_path` for sync-md tests so `goals/index.md` writes never touch the real repo. `run_cli()` extended to accept an optional `cwd` parameter (default keeps current REPO_ROOT behavior). (Spec §2 row "Test isolation".)

```python
#!/usr/bin/env python3
"""Auto-sync goals/index.md from SQLite state.

Two layers:
- Pure functions (this file's top section): `render_index_md`,
  `compute_completion_pct`, `_split_header`, `_group_and_sort`,
  `group_tasks_by_goal`. No I/O; no DB access. Independently testable.
- File-I/O function (`sync_index_md`, Task 2): reads DB, calls pure
  functions, writes the file. Atomic write.

DB access happens only inside `sync_index_md` (Task 2). Pure functions
take goals / tasks as arguments so tests can drive them with fixtures.
"""

from __future__ import annotations

import re
from collections.abc import Iterable

# ---- public constants ----

STATUS_LABELS: dict[str, str] = {
    "active": "进行中",
    "paused": "已暂停",
    "completed": "已完成",
}

_GROUP_ORDER: list[str] = ["active", "paused", "completed"]

# Matches a link line in goals/index.md: "- [<name>](<slug>/goal.md)".
# Whitespace at line start tolerated for robustness.
_LINK_LINE_RE = re.compile(r"^\s*-\s+\[.*\]\(.*/goal\.md\)")


# ---- pure helpers ----

def compute_completion_pct(tasks: list[dict]) -> int:
    """Integer percentage 0..100.

    Counts only tasks whose `status == "done"`. Returns 0 for empty input
    (avoids ZeroDivisionError; spec §4.3 mandates this).
    """
    total = len(tasks)
    if total == 0:
        return 0
    done = sum(1 for t in tasks if t.get("status") == "done")
    return round(done * 100 / total)


def _group_and_sort(goals: list[dict]) -> list[list[dict]]:
    """Bucket goals by status into the three fixed buckets, sorted by slug.

    Returns a 3-element list: [active_group, paused_group, completed_group].
    Each group is independently sorted by slug (Unicode codepoint order).
    Empty input yields three empty lists.
    """
    groups: dict[str, list[dict]] = {s: [] for s in _GROUP_ORDER}
    for g in goals:
        status = g.get("status", "")
        if status in groups:
            groups[status].append(g)
    return [sorted(groups[s], key=lambda g: g["slug"]) for s in _GROUP_ORDER]


def _split_header(content: str) -> tuple[str, int]:
    """Return (header_text, first_list_line_index).

    `header_text` is everything before the first line matching `_LINK_LINE_RE`,
    with trailing newlines stripped. `first_list_line_index` is the 0-based
    line index of the first link line, or `len(lines)` if none exists.

    Lines are split with `splitlines(keepends=True)` so the header content
    is preserved byte-for-byte (modulo the final newline strip).
    """
    lines = content.splitlines(keepends=True)
    for i, line in enumerate(lines):
        if _LINK_LINE_RE.match(line):
            return ("".join(lines[:i]).rstrip("\n"), i)
    return (content.rstrip("\n"), len(lines))


def group_tasks_by_goal(tasks: Iterable[dict]) -> dict[str, list[dict]]:
    """Group a flat task list by their `goal_slug` field.

    Tasks missing `goal_slug` are skipped silently (defensive).
    """
    grouped: dict[str, list[dict]] = {}
    for t in tasks:
        slug = t.get("goal_slug")
        if not slug:
            continue
        grouped.setdefault(slug, []).append(t)
    return grouped


# ---- pure main entry point ----

def render_index_md(
    goals: list[dict],
    tasks_by_goal: dict[str, list[dict]],
    header_text: str,
) -> str:
    """Render the body of goals/index.md.

    Output structure (spec §4.2):
        <header_text with trailing newline stripped>
        <blank line if header_text is non-empty>
        ## 进行中
        - [<name>](<slug>/goal.md) — 状态：进行中 — 完成率 <P>%
        ... (sorted by slug)
        ## 已暂停     (only if non-empty)
        ...
        ## 已完成     (only if non-empty)
        ...
        <final \n>

    Empty groups emit no heading. Goal slugs without entries in
    `tasks_by_goal` are treated as having 0 tasks (completion 0%).
    """
    parts: list[str] = []
    if header_text:
        parts.append(header_text)
        parts.append("")  # blank line after header

    grouped = _group_and_sort(goals)
    for status_key, group_goals in zip(_GROUP_ORDER, grouped):
        if not group_goals:
            continue
        parts.append(f"## {STATUS_LABELS[status_key]}")
        parts.append("")  # blank line after heading
        for g in group_goals:
            slug = g["slug"]
            name = g["name"]
            label = STATUS_LABELS[status_key]
            pct = compute_completion_pct(tasks_by_goal.get(slug, []))
            parts.append(
                f"- [{name}]({slug}/goal.md) — 状态:{label} — 完成率 {pct}%"
            )
        parts.append("")  # blank line after group

    body = "\n".join(parts)
    # Strip trailing whitespace, then add a single trailing newline.
    return body.rstrip() + "\n"
```

```python
class TestSyncIndexMd:
    def _seed_db(self, tmp_path: Path, goals: list[dict], tasks: list[dict]) -> None:
        """Seed a minimal SQLite DB with the schema + given goals/tasks.

        Uses TODO_DB_PATH so `sync_index_md`'s db.list_goals() / db.list_tasks()
        read this DB. Each goal's goal.md is created on disk if absent.
        """
        import os
        import sqlite3
        db_path = tmp_path / "todos.db"
        schema_path = REPO_ROOT / "data" / "schema.sql"
        with sqlite3.connect(str(db_path)) as conn:
            conn.executescript(schema_path.read_text(encoding="utf-8"))
            conn.executescript(
                "CREATE TABLE schema_version ("
                "  version INTEGER PRIMARY KEY,"
                "  applied_at TEXT NOT NULL"
                ");"
                "INSERT INTO schema_version VALUES (1, '2026-08-04T00:00:00');"
            )
            conn.execute("ALTER TABLE tasks ADD COLUMN started_at TEXT")
            for g in goals:
                conn.execute(
                    "INSERT INTO goals (slug, name, description, status, "
                    "total_tasks, completed_tasks, created_at, updated_at) "
                    "VALUES (?, ?, '', ?, 0, 0, '2026-08-04T00:00:00', "
                    "'2026-08-04T00:00:00')",
                    (g["slug"], g["name"], g["status"]),
                )
                (tmp_path / "goals" / g["slug"]).mkdir(parents=True, exist_ok=True)
                (tmp_path / "goals" / g["slug"] / "goal.md").write_text(
                    f"# {g['name']}\n", encoding="utf-8"
                )
            for t in tasks:
                conn.execute(
                    "INSERT INTO tasks (id, goal_slug, sequence, title, "
                    "description, estimated_hours, depends_on, status, "
                    "last_reminded_at, completed_at, created_at, updated_at) "
                    "VALUES (?, ?, ?, '', 0.0, '[]', ?, NULL, NULL, "
                    "'2026-08-04T00:00:00', '2026-08-04T00:00:00')",
                    (t["id"], t["goal_slug"], t["sequence"], t["status"]),
                )
            conn.commit()
        os.environ["TODO_DB_PATH"] = str(db_path)

    def test_creates_index_md_if_missing(self, tmp_path):
        self._seed_db(tmp_path,
                      goals=[{"slug": "foo", "name": "Foo", "status": "active"}],
                      tasks=[])
        result = sync_md.sync_index_md(tmp_path / "goals")
        assert result.path == tmp_path / "goals" / "index.md"
        assert (tmp_path / "goals" / "index.md").exists()
        content = (tmp_path / "goals" / "index.md").read_text(encoding="utf-8")
        assert "## 进行中" in content
        assert "- [Foo](foo/goal.md)" in content

    def test_preserves_existing_header(self, tmp_path):
        # Pre-create index.md with a custom header.
        goals_dir = tmp_path / "goals"
        goals_dir.mkdir(parents=True, exist_ok=True)
        (goals_dir / "index.md").write_text(
            "# 我的目标索引\n\n由 sync-md 自动维护。\n",
            encoding="utf-8",
        )
        self._seed_db(tmp_path,
                      goals=[{"slug": "x", "name": "X", "status": "active"}],
                      tasks=[])
        sync_md.sync_index_md(goals_dir)
        content = (goals_dir / "index.md").read_text(encoding="utf-8")
        # Header bytes preserved.
        assert content.startswith("# 我的目标索引\n\n由 sync-md 自动维护。\n")
        # Then the regenerated list follows.
        assert "## 进行中" in content
        assert "- [X](x/goal.md)" in content

    def test_warns_on_orphan_directory(self, tmp_path, capsys):
        self._seed_db(tmp_path,
                      goals=[{"slug": "real", "name": "R", "status": "active"}],
                      tasks=[])
        # Create an orphan goal dir (no DB row).
        (tmp_path / "goals" / "orphan").mkdir(parents=True, exist_ok=True)
        (tmp_path / "goals" / "orphan" / "goal.md").write_text("# Orphan\n", encoding="utf-8")
        sync_md.sync_index_md(tmp_path / "goals")
        captured = capsys.readouterr()

        # (SyncResult is returned by sync_index_md; capture via re-call.)
```

```python
def sync_index_md(goals_root: Path) -> SyncResult:
    """Read DB state, render goals/index.md, write atomically.

    Algorithm:
    1. Ensure `goals_root` exists (mkdir parents, exist_ok).
    2. Read existing goals/index.md if present → header_text via _split_header.
    3. db.list_goals() (no status filter) and db.list_tasks() (no goal_slug filter).
    4. Detect orphan dirs: walk goals_root/<slug>/ subdirs, compare against
       DB goal slugs. Any dir without a matching DB row is a warning.
    5. Detect missing goal.md: any DB goal whose goals/<slug>/goal.md is
       absent on disk is a warning. The link is still rendered.
    6. Call render_index_md(goals, group_tasks_by_goal(tasks), header_text).
    7. Parse the OLD list section (if index.md existed) to extract
       per-slug old lines. Compute changed / unchanged against the
       freshly rendered lines.
    8. Atomic write: goals_root/index.md.tmp → Path.replace() → goals_root/index.md.
    9. Return SyncResult.

    Raises OSError if the atomic write fails (caller decides exit code).
    """
    # Lazy import to keep this module testable without db dependencies
    # for the pure-function tests.
    import db  # noqa: PLC0415

    goals_root = Path(goals_root)
    goals_root.mkdir(parents=True, exist_ok=True)
    index_path = goals_root / "index.md"

    # 1. Read existing header (if any).
    header_text = ""
    header_preserved = False
    if index_path.exists():
        content = index_path.read_text(encoding="utf-8")
        header_text, _ = _split_header(content)
        header_preserved = bool(header_text) or _split_header(content)[1] > 0

    # 2. Read DB.
    goals = db.list_goals()  # no status filter
    tasks = db.list_tasks()  # all goals
    tasks_by_goal = group_tasks_by_goal(tasks)

    # 3. Detect orphans (dirs without DB rows) and missing goal.md.
    warnings: list[str] = []
    db_slugs = {g["slug"] for g in goals}
    if goals_root.exists():
        for entry in sorted(goals_root.iterdir()):
            if not entry.is_dir() or entry.name == "index.md":
                continue
            if entry.name not in db_slugs:
                warnings.append(
                    f"goal dir 'goals/{entry.name}/' has no DB row — skipped"
                )
            elif not (entry / "goal.md").exists():
                warnings.append(
                    f"goal '{entry.name}' has no goals/{entry.name}/goal.md"
                )

    # 4. Detect old per-slug lines (for change tracking).
    old_lines: dict[str, str] = {}
    if index_path.exists():
        old_text = index_path.read_text(encoding="utf-8")
        for line in old_text.splitlines():
            m = re.match(
                r"^\s*-\s+\[(?P<name>[^\]]*)\]\((?P<slug>[^)]+)/goal\.md\)"
                r"\s+—\s+状态[：:](?P<status>[^—]+)—\s+完成率\s+(?P<pct>\d+)%",
                line,
            )
            if m:
                slug = m.group("slug")
                # Re-render the line using current label mapping to normalize.
                status_key = _status_key_from_label(m.group("status").strip())
                if status_key:
                    old_lines[slug] = (
                        f"- [{m.group('name')}]({slug}/goal.md) — 状态:"
                        f"{STATUS_LABELS[status_key]} — 完成率 "
                        f"{m.group('pct')}%"
                    )

    # 5. Render.
    rendered = render_index_md(goals, tasks_by_goal, header_text)
    new_lines: dict[str, str] = {}
    for line in rendered.splitlines():
        m = re.match(
            r"^-\s+\[(?P<name>[^\]]*)\]\((?P<slug>[^)]+)/goal\.md\)",
            line,
        )
        if m:
            new_lines[m.group("slug")] = line

    all_slugs = set(old_lines) | set(new_lines)
    changed = sorted(s for s in all_slugs if old_lines.get(s) != new_lines.get(s))
    unchanged = sorted(s for s in all_slugs if s not in changed)

    # 6. Atomic write.
    tmp_path = index_path.with_suffix(index_path.suffix + ".tmp")
    tmp_path.write_text(rendered, encoding="utf-8")
    tmp_path.replace(index_path)

    by_status: dict[str, int] = {s: 0 for s in _GROUP_ORDER}
    for g in goals:
        by_status[g["status"]] = by_status.get(g["status"], 0) + 1

    return SyncResult(
        path=index_path,
        synced_count=len(goals),
        by_status=by_status,
        changed=changed,
        unchanged=unchanged,
        warnings=warnings,
        header_preserved=header_preserved,
    )


def _status_key_from_label(label: str) -> str | None:
    """Reverse STATUS_LABELS map (best-effort, used for change detection)."""
    for k, v in STATUS_LABELS.items():
        if v == label:
            return k
    return None
```

```python
def _autosync_index_md() -> None:
    """Re-render goals/index.md after a successful CRUD op.

    Captures all exceptions and writes them to stderr. Never raises,
    never exits. The calling subcommand has already succeeded; sync
    failure must not roll back the user's operation.

    On a DB-uninitialized error, silently does nothing (the calling
    subcommand already exited 2 before reaching us).
    """
    try:
        # Skip silently if schema_version is absent.
        with db.get_conn() as conn:
            row = conn.execute(
                "SELECT name FROM sqlite_master "
                "WHERE type='table' AND name='schema_version'"
            ).fetchone()
            if row is None:
                return
        sync_index_md(Path("goals"))
    except Exception as exc:
        print(f"warning: sync-md failed: {exc}", file=sys.stderr)
```
